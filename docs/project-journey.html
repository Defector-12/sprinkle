三个核心边界

后续理解任何模块时，都先判断它位于哪条边界的哪一侧。

02
解析边界

解析决定系统能否看见信息；检索只能从 ArticleDocument 中选择，无法找回未解析内容。

记忆边界

完整 messages、本轮 selectedHistory 和派生 checkpoint 是三种不同的数据，可信度也不同。

存储边界

正文、焦点、诊断和检查点只进 session；长期 local 归档只保存成功问答文本。

推荐学习路线

顺序遵循“先建立运行时骨架，再理解算法，最后回到 UI 和工程保障”。 不建议一开始逐行阅读两个大型 React 组件。
