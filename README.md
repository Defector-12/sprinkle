# Context Reader

Context Reader 是一个 Chrome / Edge Manifest V3 浏览器插件。普通网页默认保持休眠；用户点击浏览器工具栏图标后，插件才在本地理解当前页面并显示悬浮助手。用户可以围绕全文或选中文字就地提问，不同标签页与页面的上下文彼此隔离。

## 当前能力

- 工具栏点击后读取当前网页的标题、章节、段落、列表和代码块
- 未启用页面不读取内容、不显示悬浮球
- 显示理解中、已就绪、缺少 API Key、回答中和失败状态
- 部分读取时提供按需打开的结构诊断、原因详情和重新理解入口
- 支持 X Article 及使用 `div/span` 渲染的 React 长文正文回退提取
- 多个正文候选会选择可读内容最丰富的一项，并补采混合结构中的后续自定义文本
- 选中文字后通过页面内快捷按钮发起提问
- 引用问答保留多级章节路径，并只使用当前引用锚点附近内容，避免同名小节和历史回答串扰
- 支持点选、双击引用页面图片，以及自由框选可见页面区域提问
- 点击悬浮球或工具栏图标展开网页内对话卡片
- Shadow DOM 使用标准 HTML 宿主，兼容 Reddit 等会隐藏未注册自定义元素的网站
- 可从悬浮窗打开全页学习工作台，左侧阅读资料、右侧连续对话
- 学习工作台支持拖动或键盘调整左右栏比例；窄窗口自动切换为上下布局，并共享原页面上下文与对话
- 工作台按原文位置回填图片、SVG 与 Canvas 图表
- 工作台保留代码换行、正文显式换行和列表边界；划词后就近显示“提问”按钮，并支持显式点图和框选引用
- 工作台根据正文标题重建可跳转目录，并保留表格与 MathML 数学公式
- 当前视图新收到的模型回答使用逐字效果；历史、刷新和跨视图同步内容直接完整显示
- 三轮提问后显示低干扰的问题历史短线，悬停展开摘要并可点击定位
- 可显式开启本地学习记录，在独立页面按网址搜索、查看和删除完整问答；网址栏可调宽和收起
- 可从学习记录继续提问；原页面上下文仍有效时直接复用，否则重新打开并解析
- 长对话会保留完整记录，并按“最近对话 + 相关旧问答”构建长期记忆
- 网页版与悬浮窗发送后自动跟随最新消息，输入框随内容增高
- 两套界面均可最大化输入框；最大化时 Enter 换行，恢复后 Enter 发送
- 模型回答支持安全的 Markdown/GFM 排版，包括标题、列表、代码、链接和表格
- 每条引用提问保留发送时的文字或图片映射，历史对话可回看提问依据
- 支持拖动悬浮球、移动及缩放整个对话框，并可显式停止理解当前页面
- 基于相关文章片段和连续对话构建模型请求
- 全文总结类问题按原文顺序使用已解析全文；超长文章均匀覆盖首、中、尾并明确提示预算截断
- 文字、图片和框选区域问题统一使用 DeepSeek 视觉模型
- 不展示原文出处、引用卡片或定位入口
- 按 `tabId + 规范化 URL` 隔离和恢复页面上下文
- 标签页关闭后清除正文和临时上下文
- 可选地在本地保留、检索和管理问答文本
- 所有模型请求使用用户提供的 DeepSeek API Key

## 技术栈

- WXT 0.20
- React 19
- TypeScript 7
- Vitest 4
- Manifest V3 Content Script + Shadow DOM

## 本地开发

要求 Node.js 22.13+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

模型实现配置通过本地环境变量提供：

```bash
VITE_MODEL_API_URL=https://api.deepseek.com/chat/completions
VITE_MODEL_ID=deepseek-v4-flash-vision-exp
```

这些值会进入浏览器扩展包，只能用于公开的接口地址和模型标识。DeepSeek API Key 不得写入环境变量或源码，由用户在扩展设置页输入。

## 构建与加载

```bash
pnpm build
pnpm build:edge
```

构建目录：

- Chrome：`.output/chrome-mv3`
- Edge：`.output/edge-mv3`

在 `chrome://extensions` 或 `edge://extensions` 中启用开发者模式，然后选择“加载已解压的扩展程序”并指定对应构建目录。

## 验证

```bash
pnpm typecheck
pnpm test

pnpm check
```

覆盖率门槛应用于可确定性测试的核心逻辑、会话存储和模型边界。浏览器 entrypoints 通过 Chrome / Edge 构建与解压扩展加载进行验证。

## 隐私边界

- 页面加载后保持休眠；只有用户点击工具栏图标或从学习记录继续提问时才在本地读取正文。
- 页面理解本身不会调用模型 API，只有用户发送问题才会请求模型。
- `<all_urls>` 用于在原网页和扩展工作台中调用 `captureVisibleTab`；截图只在用户主动点选图片或框选区域时发生，本地图片由用户主动选择或粘贴。
- DeepSeek API Key 只保存在 `browser.storage.local`。
- 页面正文只进入 `browser.storage.session`。
- 标签页关闭后，删除对应的临时页面上下文。
- 开启“保存学习记录”后，只归档完整问答文本及不含图片数据的引用说明。
- 停止理解当前页面不会删除已保存的学习记录；删除记录必须由用户单独确认。

## 当前限制

- 正式使用前必须确定并配置具体模型 API。
- DeepSeek 视觉模型使用 OpenAI-compatible Chat Completions，同时处理文字与图片请求。
- 不支持 PDF、视频、iframe 内容和跨文章联合问答。
- 无限滚动、虚拟列表或仍在异步加载的正文只能读取当前已进入 DOM 的内容；检测到加载态时会标记为部分读取。
- 支持上传或粘贴不超过 5 MB 的 JPEG、PNG、GIF 或 WebP 本地图片；页面图片与区域框选仍基于当前可见页面截图，不支持截取视口之外的内容。
- 学习工作台展示解析后重建的阅读视图，不运行原网页脚本，也不保证还原动态表格和交互组件。
